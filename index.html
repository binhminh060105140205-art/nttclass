Nhập học sinh từ file

Hỗ trợ Excel, CSV và bảng trong file Word (.docx). File chỉ được đọc trên thiết bị này.

1. Chọn file danh sách

Dòng đầu tiên nên là tên cột. Word cần trình bày danh sách dưới dạng bảng.

2. Ghép cột dữ liệu

Hệ thống đã tự nhận diện. Có thể đổi lại nếu tiêu đề trong file khác.

3. Kiểm tra trước khi nhập

Dòng lỗi sẽ không được gửi lên hệ thống. Dòng cảnh báo vẫn có thể nhập.
